# 🏸 羽毛球比赛计分器 (Badminton Scoreboard)

一款专为羽毛球比赛设计的安卓计分软件，界面简洁醒目，支持大屏横向双色计分与标准加分赛规则。

---

## 🌟 核心特性

- **🎨 Neo-Pop Arcade 新潮街机视觉风格**：
  - 复古波点背景与暖米白主基调（#FBF7EE），搭配 3.2dp 粗黑轮廓（#1E1B18）与立体投影。
  - 支持 **15 分竞速局** 与 **31 分大师赛** 直选，横竖屏自适应切换。
  - 赛制卡片支持物理实体 3D 下压回弹反馈，打击感十足。
  - 支持快捷修改对战队伍名称（默认：蓝方 VS 红方）。
- **🏸 专业羽毛球发球区指示与加分赛（Deuce）机制**：
  - **左单右双原则（0算双数）**：自动实时指示当前发球方是在左区还是右区发球。
  - **15 分制**：战至 14-14 平后进入加分赛，须净胜 2 分胜出，**21 分封顶**。
  - **31 分制**：战至 30-30 平后进入加分赛，须净胜 2 分胜出，**36 分封顶**。
  - 触发加分赛时自动提示当前封顶分。
- **⚡ 横屏沉浸式极简计分与羽毛球扣杀特效**：
  - 进入比赛自动锁定全屏横屏模式，左右双色高对比分区（科技蓝 vs 激情红）。
  - 单击大色块触发羽毛球飞行动画与扣杀爆炸特效，支持**多羽毛球并发快速连击**，不打断飞行动画。
- **🎛️ 顶部居中多功能悬浮控制栏**：
  - 折叠为顶部防误触矩形，点击后展开。
  - 双方独立 【+1 / -1】 加减分按钮，支持【撤销 (Undo)】、【换边 (Swap)】、【重置局分 (Reset)】。
  - **3.5 秒无触摸自动收起**。
- **🏆 街机风胜利结算弹窗**：
  - 比赛胜出时自动触发一次性礼炮喷射彩色缎带与彩屑效果（🎉）。
  - 专属 Neo-Pop 3D 实体按键【主菜单】、【换边再战】、【再来一局】。

## 🛠️ 技术栈

- **Language**: Kotlin 1.9.22
- **UI Framework**: Jetpack Compose (Material3)
- **Compile SDK**: 34 (Android 14)
- **Minimum SDK**: 24 (Android 7.0+)
- **Build Tool**: Gradle 8.4 + AGP 8.3.0

---

## 🚀 编译与安装

```bash
# 编译 Debug APK
./gradlew assembleDebug

# 安装到连接的 Android 设备
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
