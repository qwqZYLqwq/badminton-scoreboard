# 🏸 羽毛球比赛计分器 (Badminton Scoreboard)

一款专为羽毛球比赛设计的安卓计分软件，界面简洁醒目，支持大屏横向双色计分与标准加分赛规则。

---

## 🌟 核心特性

- **🏸 现行国际标准赛制与三局两胜**：
  - **21 分正规赛**：20:20 平进入加分赛须净胜 2 分，**30 分封顶**；采用标准三局两胜制。
  - **15 分竞速局**：14:14 平进入加分赛须净胜 2 分，**21 分封顶**；同样支持三局两胜。
  - 顶部控制栏居中醒目显示局分（大比分），赛末自动决出全场胜者。
- **⏱️ 局中技术暂停与局间休息系统**：
  - **局中技术暂停**：每局领先方达到 **11 分**（15分制为 8 分）时触发 60 秒休息；第三局（决胜局）达到 11 分时自动提示双方交换场地。
  - **局间休息**：单局结束后进入 120 秒局间休息并自动提示换边，局分清零进入下一局。
  - **全屏沉浸护眼地胶绿休息界面**：球场网格底纹与动感倒计时，支持**双击屏幕快速跳过**；可在主页自由选择是否开启休息计时。
- **🔄 高对比双色场地与换边动态联动**：
  - 左右半场采用高对比双色渐变分区（深浅蓝 VS 深浅红）。
  - 局间换边、决胜局换边或手动点击【换边】时，**左右半场背景底色、顶部控制条队伍颜色与队伍名称完全同步调换**，队伍与半场颜色始终保持一致。
- **👥 单打 / 双打模式与专业站位发球规则**：
  - 主页可一键切换【单打】与【双打】模式。
  - **严谨遵循双打规则**：发球方得分时发球员与队友换边继续发球，接发球方位置不变；换发球权时双方站位均不改变，由新发球方根据其总分确定发球员。
  - 实时指示当前发球半区（左单右双，0算双数），双打模式下精准显示当前发球员与接发球员姓名。
- **🧭 智能发球辅助系统（Serve Assist）**：
  - **半场象限分割**：开启后计分界面增加横向中线，将球场清晰划分为四个发球发分区。
  - **动态对角发球指引线**：屏幕实时绘制虚线箭头指引发球站位与击球方向。
  - **防呆反装颠倒模式**：支持一键将发球辅助箭头方向反转，满足远离控制栏或不同视角的裁判执裁需求。
- **⚡ 多球并发飞行与扣杀爆炸特效**：
  - 单击大色块触发羽毛球抛物线飞行与扣杀爆炸特效，支持**多羽毛球并发快速连击**，不打断飞行动画连贯性。
  - 落地后平滑计分，并在关键赛点与技术暂停点提供完备的时序与并发保护。
- **🎨 Neo-Pop Arcade 新潮街机视觉风格**：
  - 复古波点背景与暖米白主基调（#FBF7EE），搭配 3.2dp 粗黑轮廓（#1E1B18）与立体投影。
  - 赛制卡片支持物理实体 3D 下压回弹反馈，打击感十足。
  - 比赛胜出时自动触发一次性礼炮喷射彩色缎带与彩屑效果（🎉），弹窗完整呈现各局历史小比分。

## 🛠️ 技术栈

- **Language**: Kotlin 1.9.22
- **UI Framework**: Jetpack Compose (Material3)
- **Compile SDK**: 34 (Android 14)
- **Minimum SDK**: 24 (Android 7.0+)
- **Build Tool**: Gradle 8.4 + AGP 8.3.0
